CASE STUDY · 05 / 06

SIGNATURE ENGINE

מערכת לחתימות מייל. מערכת חכמה ליצירה וניהול של חתימות מייל אחידות, עם תצוגה חיה וחוויית עריכה פשוטה.

שנה
2025
תפקיד
פיתוח Full‑Stack · עיצוב ממשק
לעורך החתימות

01 האתגר

חתימות מייל נראות אחרת אצל כל אחד: פונטים, צבעים ופרטים לא אחידים. צריך כלי שמוציא חתימה אחידה בכמה שדות.

02 הגישה

  1. בחירה מגלריית תבניות, טופס פרטים עם ולידציה, והפקה של חתימה כטקסט וכ‑HTML.
  2. ממשק API שמאפשר להפיק חתימות לקבוצה שלמה בבת אחת.
  3. בדמו: עריכה בזמן אמת והעתקה, והמידע נשאר בדף ואינו נשלח לשרת.

03 מה נבנה

תצוגה חיה

כל שינוי בטופס מופיע מיד בחתימה.

הפקה בכמות

API ליצירת חתימות לצוות שלם.

טקסט ו‑HTML

חתימה שמתאימה גם למערכות מייל מגבילות.
